# Simple Accounting

Simple Accounting is a Flutter application for managing personal finances. Track income and expenses, categorize transactions, and visualize spending trends with interactive charts.


## Features

- Create, edit and delete financial records (income/expense)
- Organize transactions by categories
- View transaction history and details
- Interactive charts for spending analysis

## Installation
To install the app on your Android device:
- Download the latest APK from the Releases page.

## Usage

### Accounting Page
- Tap the "+" button to add a new transaction: select a category, enter amount and date.

### History Page
- Tap the date to select a month.
- Browse the amount of the month by categories.
- Long press a section in pie chart to view all transaction.
- Edit transection: right swipe to remove, left swipe to edit.

### Analysis Page
- View interactive charts of income and expense or over time.
- Statistics of income and expense.

## Development
To build and run the app from source, ensure you have the following prerequisites:
- Flutter SDK (>=3.0.0)
- Dart SDK (comes with Flutter)
- Android SDK or Xcode for iOS builds
